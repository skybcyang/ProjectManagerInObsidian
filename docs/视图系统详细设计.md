## 1. 系统概述

视图系统采用**统一视图引擎**架构，所有视图（看板、级联、时间视图）共享统一的配置、筛选和渲染机制。

### 1.1 核心设计理念

- **统一配置**：通过 YAML 配置 `pm-view` 代码块定义视图
- **统一筛选**：`ToolbarController` + `EntityTreeSelector` 提供实体类型/层级/状态/优先级/负责人多维度筛选
- **筛选持久化**：筛选条件自动保存到 Markdown 代码块
- **统一卡片**：所有视图使用统一的卡片式 EntityCard 组件
- **视图只读**：视图仅用于展示和导航，不允许在视图内直接修改数据
- **SelectCell 风格**：所有下拉选择器采用统一的 Badge 风格设计
- **级联联动**：树形选择器支持版本→项目→特性的层级联动

## 2. 配置系统

### 2.1 配置格式 (YAML)

```yaml
# 基本配置
mode: kanban              # 视图模式: kanban/cascade/timeview
entityType: feature       # 实体类型: version/project/feature

# 标题
title: 我的视图

# 层级筛选（多选，与树形选择器联动）
versions: [ver_xxx]       # 版本ID列表
projects: [proj_xxx]      # 项目ID列表
features: [feat_xxx]      # 特性ID列表

# 属性筛选（下拉选择）
status: in-progress       # 状态筛选
priority: high            # 优先级筛选
owner: "张三"             # 负责人筛选
tag: "重要"               # 标签筛选

# 排序配置
sortBy: endDate           # name/startDate/endDate/priority/progress/created
sortOrder: desc           # asc/desc

# 分组（看板视图用）
groupBy: status           # status/priority

# 限制数量
limit: 20

# 级联视图选项（仅 cascade 模式）
expanded: true            # 默认展开
```

### 4.3 级联选择机制

**三态级联勾选**：

```typescript
private getNodeState(node: TreeNode): 'checked' | 'indeterminate' | 'unchecked' {
  const directlySelected = this.selectedIds.has(node.id);
  if (!node.children || node.children.length === 0) {
    return directlySelected ? 'checked' : 'unchecked';
  }
  const childStates = node.children.map(c => this.getNodeState(c));
  const allChecked = childStates.every(s => s === 'checked');
  const someSelected = childStates.some(s => s === 'checked' || s === 'indeterminate');

  if (directlySelected || allChecked) return 'checked';
  if (someSelected) return 'indeterminate';
  return 'unchecked';
}

private toggleNodeSelection(node: TreeNode, checked: boolean): void {
  if (checked) {
    this.selectedIds.add(node.id);
    this.selectAllChildren(node);   // 向下级联全选
    this.checkAncestors(node);      // 向上检查父节点
  } else {
    this.selectedIds.delete(node.id);
    this.deselectAllChildren(node); // 向下级联取消
  }

  this.hasSelectionChanged = true;
  this.refreshCheckboxes();
  this.updateTriggerDisplay(...);
  // 注意：不在此处触发 onSelect，避免下拉框关闭
}
```

### 4.4 筛选结果处理

**树形选择器采用延迟回调策略**：勾选节点时不立即触发 `onSelect`，而是标记 `hasSelectionChanged = true`，待下拉框关闭时才统一回调。这避免了 `app.vault.modify()` 导致 Obsidian 重绘代码块、下拉框被强制销毁的问题。

```typescript
// EntityTreeSelector.ts - 延迟回调
private closeDropdown(skipCallback = false): void {
  if (!skipCallback && this.hasSelectionChanged) {
    this.updateSelection();      // 此时才触发 onSelect
    this.hasSelectionChanged = false;
  }
  if (this.dropdownEl) {
    this.dropdownEl.remove();
    this.dropdownEl = undefined;
  }
}
```

**ToolbarController 数组化筛选处理**：

```typescript
// ToolbarController 树形筛选处理
private handleTreeSelection(selection: TreeSelection | null): void {
  // 先显式清空旧字段，避免残留
  this.filters.versions = undefined;
  this.filters.projects = undefined;
  this.filters.features = undefined;

  if (!selection) {
    this.onFilterChange();
    return;
  }

  switch (this.currentEntityType) {
    case 'version':
      if (selection.versionIds?.length) {
        this.filters.versions = selection.versionIds;
      }
      break;
    case 'project':
      if (selection.projectIds?.length) {
        this.filters.projects = selection.projectIds;
      }
      break;
    case 'feature':
      if (selection.featureIds?.length) {
        this.filters.features = selection.featureIds;
      }
      break;
  }

  this.onFilterChange();
}

// ToolbarController 筛选变更回调
private onFilterChange(): void {
  const cleanFilters: ViewConfig = {
    mode: this.filters.mode,
    entityType: this.filters.entityType,
  };

  // 显式清空旧的层级字段，避免 { ...config, ...cleanFilters } 时保留旧值
  cleanFilters.versions = undefined;
  cleanFilters.projects = undefined;
  cleanFilters.features = undefined;

  switch (this.currentEntityType) {
    case 'version':
      if (this.filters.versions?.length) {
        cleanFilters.versions = this.filters.versions;
      }
      break;
    case 'project':
      if (this.filters.projects?.length) {
        cleanFilters.projects = this.filters.projects;
      } else if (this.filters.versions?.length) {
        cleanFilters.versions = this.filters.versions;
      }
      break;
    case 'feature':
      if (this.filters.features?.length) {
        cleanFilters.features = this.filters.features;
      } else if (this.filters.projects?.length) {
        cleanFilters.projects = this.filters.projects;
      } else if (this.filters.versions?.length) {
        cleanFilters.versions = this.filters.versions;
      }
      break;
  }

  if (this.filters.status) cleanFilters.status = this.filters.status;
  if (this.filters.priority) cleanFilters.priority = this.filters.priority;
  if (this.filters.owner) cleanFilters.owner = this.filters.owner;

  this.onChange(cleanFilters);
  this.saveFiltersToCodeBlock();
}
```

## 5. 视图渲染器详解

### 5.1 渲染器注册表 (RendererRegistry)

采用**注册表模式**管理渲染器，避免 switch 语句：

```typescript
// RendererRegistry.ts
export class RendererRegistry {
  private static renderers = new Map<ViewMode, RendererConstructor>();

  static register(mode: ViewMode, constructor: RendererConstructor): void {
    this.renderers.set(mode, constructor);
  }

  static create(mode: ViewMode, ...args: any[]): BaseRenderer | null {
    const Constructor = this.renderers.get(mode);
    return Constructor ? new Constructor(...args) : null;
  }
}

// 各渲染器在文件末尾自注册
RendererRegistry.register('kanban', KanbanRenderer);
RendererRegistry.register('cascade', CascadeRenderer);
// ...
```

### 6.2 DataService 过滤逻辑

```typescript
applyFilters(entities: Entity[], config: ViewConfig): Entity[] {
  return entities.filter((entity) => {
    // 状态过滤
    if (config.status && 'status' in entity && entity.status !== config.status) {
      return false;
    }

    // 优先级过滤
    if (config.priority && 'priority' in entity && entity.priority !== config.priority) {
      return false;
    }

    // 负责人过滤
    if (config.owner && entity.owner !== config.owner) {
      return false;
    }

    // 标签过滤
    if (config.tag && 'tags' in entity && !entity.tags?.includes(config.tag)) {
      return false;
    }

    // 版本ID过滤（项目/特性）
    if (config.version && 'versionId' in entity && entity.versionId !== config.version) {
      return false;
    }

    // 项目ID过滤（特性）
    if (config.project && 'projectId' in entity && entity.projectId !== config.project) {
      return false;
    }

    return true;
  });
}
```

### 6.3 筛选持久化机制

```typescript
// CodeBlockConfigService.ts
async saveConfig(
  sourcePath: string,
  codeBlockIndex: number,
  updates: Record<string, unknown>,
  options?: SaveConfigOptions
): Promise<void> {
  // 1. 读取文件内容
  const file = this.app.vault.getAbstractFileByPath(sourcePath);
  const content = await this.app.vault.read(file as TFile);

  // 2. 构建新内容（合并更新，保留指定键）
  const newContent = this.buildNewContent(content, codeBlockIndex, updates, options);

  // 3. 写回文件
  await this.app.vault.modify(file as TFile, newContent);
}

// 防抖保存（300ms）
debouncedSave(sourcePath, codeBlockIndex, updates, delay = 300): void {
  const key = `${sourcePath}:${codeBlockIndex}`;

  // 清除之前的定时器
  const existingTimeout = this.pendingSave.get(key);
  if (existingTimeout) {
    clearTimeout(existingTimeout);
  }

  // 设置新的定时器
  const timeout = setTimeout(() => {
    this.saveConfig(sourcePath, codeBlockIndex, updates);
    this.pendingSave.delete(key);
  }, delay);

  this.pendingSave.set(key, timeout);
}
```
