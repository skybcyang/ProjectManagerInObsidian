## 1. 系统概述

视图系统采用**统一视图引擎**架构，所有视图（看板、列表、网格、级联、时间线、日历）共享统一的配置和渲染机制。

### 1.1 核心设计理念

- **统一配置**：通过 YAML 配置 `pm-view` 代码块定义视图
- **统一组件**：所有视图使用 `EntityCard` 组件显示实体
- **统一筛选**：6 个筛选条件在单个横向工具栏中
- **行内编辑**：列表视图支持单元格直接编辑
- **智能联动**：筛选条件级联更新

## 2. 配置系统

### 2.1 配置格式 (YAML)

```yaml
# 基本配置
mode: kanban              # 视图模式: kanban/list/grid/cascade/timeline/calendar
entityType: feature       # 实体类型: version/project/feature

# 实体筛选
versionId: ver_xxx        # 版本ID
projectId: proj_xxx       # 项目ID
featureId: feat_xxx       # 特性ID

# 卡片字段配置（控制 EntityCard 显示）
cardFields:
  required:               # 始终显示的字段
    - name
    - priority
  optional:               # 用户可选择的字段
    - status
    - owner
    - progress
    - tags
    - description
    - actions

# 列表列配置（仅 list 模式有效）
listColumns:
  - name
  - status
  - priority
  - owner
  - dueDate
  - progress
```

### 2.2 配置向后兼容

```typescript
parseConfig(source: string): ViewConfig {
  const parsed = parseYaml(source) || {};
  return {
    mode: parsed.mode || 'kanban',
    entityType: parsed.entityType || 'feature',
    // 支持旧字段名和新字段名
    version: parsed.version || parsed.versionId,
    project: parsed.project || parsed.projectId,
    feature: parsed.feature || parsed.featureId,
    cardFields: parsed.cardFields || {
      required: ['name', 'priority'],
      optional: ['status', 'owner', 'progress']
    },
    listColumns: parsed.listColumns || ['name', 'status', 'priority', 'owner']
  };
}
```

## 3. 视图渲染器

### 3.1 基类设计 (BaseRenderer)

```typescript
abstract class BaseRenderer {
  protected app: App;
  protected cache: EntityCache;
  protected config: ViewConfig;
  protected container: HTMLElement;
  
  abstract render(container: HTMLElement): void;
  abstract refresh(): void;
  
  // 公共方法
  protected getFilteredEntities(): Entity[];
  protected createEmptyState(message: string): HTMLElement;
  protected onEntityChange(entity: Entity): void;
```

### 4.2 筛选组件

```typescript
class FilterBar {
  private versionSelect: HTMLSelectElement;
  private projectSelect: HTMLSelectElement;
  private featureSelect: HTMLSelectElement;
  private statusSelect: HTMLSelectElement;
  private prioritySelect: HTMLSelectElement;
  private ownerSelect: HTMLSelectElement;
  
  render(parent: HTMLElement, initialFilters?: Partial<ViewConfig>): HTMLElement {
    // 6个下拉框 + 重置按钮
  }
  
  // 级联更新
  updateProjectOptions(versionId: string): void;
  updateFeatureOptions(versionId: string, projectId: string): void;
  
  // 持久化
  saveFiltersToCodeBlock(): void;

```

### 4.3 级联逻辑

| 操作 | 触发 | 结果 |
|------|------|------|
| 选择版本 | versionSelect.onchange | 更新项目列表、清空特性选择 |
| 选择项目 | projectSelect.onchange | 更新特性列表 |
| 选择特性 | featureSelect.onchange | 应用筛选 |
| 点击重置 | resetBtn.onclick | 清空所有筛选条件 |

```typescript
  // 标签
  showTags: boolean;        // #tag1 #tag2
  
  // 标题大小
  smallTitle: boolean;      // 小标题模式
  
  // 操作按钮

}
```

## 6. 交互规范

### 6.1 拖拽行为

| 视图 | 拖拽源 | 放置目标 | 行为 |
|------|--------|----------|------|
| 看板 | 卡片 | 列 | 更改状态 |
| 看板 | 卡片 | 同一列 | 重新排序 |
| 列表 | 行 | 行 | 重新排序（更新序号）|

| 单元格 | 触发 | 输入方式 | 保存 |

## 8. 数据流

```
1. 用户打开包含 pm-view 代码块的笔记
              ↓
2. Obsidian 触发代码块处理器
              ↓
3. ViewEngine.render() 解析 YAML 配置
              ↓
4. 创建工具栏 + 筛选栏
              ↓
5. 调用对应 Renderer.render()
              ↓
6. Renderer 从 EntityCache 获取数据
              ↓
7. 渲染 EntityCard 组件
              ↓
8. 用户交互（筛选/编辑/拖拽）
              ↓
9. 更新 EntityCache → 刷新视图
```
