# ProjectManagerInObsidian 视图系统详细设计

## 一、视图类型总览

系统目前支持 **6 种视图模式**：

| 视图模式 | 中文名称 | 图标 | 渲染器类 | 主要用途 |
|---------|---------|-----|---------|---------|
| `kanban` | 看板视图 | 📊 | `KanbanRenderer` | 类 Trello 的拖拽看板 |
| `list` | 列表视图 | 📋 | `ListRenderer` | 表格形式，支持行内编辑 |
| `grid` | 网格视图 | ▦ | `GridRenderer` | 卡片网格布局 |
| `cascade` | 级联视图 | 🌲 | `CascadeRenderer` | 树形层级结构 |
| `timeline` | 时间线视图 | ⏱️ | `TimelineRenderer` | 水平/垂直时间轴 |
| `calendar` | 日历视图 | 🗓️ | `CalendarRenderer` | 月历视图 |

## 二、属性面板配置（重构版）

点击视图工具栏的 **「属性 ▼」** 按钮，打开属性面板进行配置。

### 2.1 基础配置（所有视图）

- **实体类型**：下拉选择（特性/项目/版本）
- **显示数量限制**：数字输入框

### 2.2 列表视图专属：表头字段勾选配置

使用**勾选框组**选择要显示的表格列：

| 字段 | 是否必选 | 说明 |
|-----|---------|-----|
| 名称 | ✅ 必选 | 始终显示，不可取消 |
| 状态 | 可选 | |
| 优先级 | 可选 | |
| 负责人 | 可选 | |
| 截止日期 | 可选 | |
| 进度 | 可选 | |
| 标签 | 可选 | |
| 版本 | 可选 | |
| 项目 | 可选 | |

**配置示例**：
```yaml
mode: list
entityType: feature
listColumns:
  - name
  - status
  - priority
  - owner
  - progress
```

### 2.3 EntityCard 视图专属：字段多选配置

使用**多选区域**选择卡片要显示的字段，分为两部分：

**必选字段**（始终显示，不可取消）：
- ✅ 名称
- ✅ 优先级

**可选字段**（用户可勾选）：
- 状态徽章
- 负责人
- 截止日期
- 进度条
- 标签
- 描述
- 父级信息
- 类型图标
- 统计信息
- 操作按钮

**配置示例**：
```yaml
mode: grid
entityType: feature
cardFields:
  required:
    - name
    - priority
  optional:
    - status
    - owner
    - progress
    - tags
    - description
    - actions
```

### 2.4 视图特定配置

| 配置项 | 适用视图 | 说明 |
|-------|---------|-----|
| 分组方式 | kanban, cascade | 按状态/优先级分组 |
| 列数 | grid | 2/3/4/5 列 |
| 展开状态 | cascade | 默认展开/折叠 |

## 四、各视图字段配置说明

### 4.1 GridRenderer（网格视图）

完全遵循 `cardFields` 配置，所有可选字段都可显示。

### 4.2 KanbanRenderer（看板视图）

遵循 `cardFields` 配置，但有以下特殊处理：
- `showStatus` 始终为 `false`（看板按状态分组，不需要显示状态徽章）
- 嵌套分组的卡片会简化显示（`smallTitle: true`）

### 4.3 CascadeRenderer（级联视图）

遵循 `cardFields` 配置，但受空间限制：
- `showOwner`, `showDueDate`, `showProgress`, `showTags`, `showParent`, `showDescription`, `showTypeIcon`, `showStats`, `showActions` 始终为 `false`
- 仅显示 `name`, `priority`, `status`
- 标题使用小字体（`smallTitle: true`）

### 4.4 CalendarRenderer（日历视图）

遵循 `cardFields` 配置，但受空间限制：
- 仅显示 `name`, `priority`, `status`
- 其他字段强制不显示

### 4.5 TimelineRenderer（时间线视图）

遵循 `cardFields` 配置，但区分方向：
- **水平时间线**：空间极小，仅显示 `name`, `priority`, `status`
- **垂直时间线**：空间充足，可显示所有配置字段

### 4.6 ListRenderer（列表视图）

遵循 `listColumns` 配置：
- 从 `getEntityFields()` 获取所有可用字段
- 根据 `listColumns` 过滤显示
- `name` 字段始终显示

## 六、ViewConfig 配置接口

```typescript
interface ViewConfig {
  mode: ViewMode;                    // 视图模式
  title?: string;                    // 标题
  entityType?: EntityType;           // 实体类型
  
  // 筛选条件
  version?: string;                  // 版本ID筛选
  project?: string;                  // 项目ID筛选
  feature?: string;                  // 特性ID筛选
  filters?: FilterGroup[];           // 组合筛选
  status?: string;                   // 状态筛选
  priority?: string;                 // 优先级筛选
  owner?: string;                    // 负责人筛选
  tag?: string;                      // 标签筛选
  
  // 排序
  sorts?: SortConfig[];              // 多字段排序
  sortBy?: string;                   // 排序字段
  sortOrder?: 'asc' | 'desc';        // 排序方向
  
  // 列配置
  columns?: ColumnConfig[];          // 列配置
  
  // ⭐ 新增：列表视图列配置
  listColumns?: ListColumnField[];   // 显示的列
  
  // ⭐ 新增：EntityCard 字段配置
  cardFields?: CardFieldsConfig;     // 卡片显示字段
  
  // 限制与分组
  limit?: number;                    // 显示数量限制
  groupBy?: string;                  // 分组方式
  
  // 视图选项
  options?: ViewOptions;             // 视图特定选项
  
  // 向后兼容
  cols?: number;
  expanded?: boolean;
  maxProjects?: number;
  maxFeaturesPerProject?: number;
}
```

## 八、属性面板实现说明

### 8.1 面板结构

```
视图属性
├── 实体类型（下拉选择）
├── 显示数量限制（数字输入）
├── [列表视图] 显示列（勾选框组）
│   ├── 名称 [必选]
│   ├── 状态
│   ├── 优先级
│   └── ...
├── [EntityCard视图] 卡片显示字段（多选区域）
│   ├── 必选字段
│   │   ├── 名称 [✓]
│   │   └── 优先级 [✓]
│   └── 可选字段
│       ├── 状态徽章 [ ]
│       ├── 负责人 [ ]
│       └── ...
├── [kanban/cascade] 分组方式（下拉）
├── [grid] 列数（下拉）
└── [cascade] 展开状态（下拉）
```

### 8.2 关键方法

| 方法 | 功能 |
|-----|-----|
| `showPropertyPanel()` | 显示属性面板 |
| `renderEntityTypeSelector()` | 渲染实体类型选择器 |
| `renderListColumnSelector()` | 渲染列表列勾选框组 |
| `renderCardFieldSelector()` | 渲染 EntityCard 字段多选区 |
| `renderGroupBySelector()` | 渲染分组方式选择器 |
| `renderColsSelector()` | 渲染网格列数选择器 |
| `renderLimitInput()` | 渲染数量限制输入框 |
