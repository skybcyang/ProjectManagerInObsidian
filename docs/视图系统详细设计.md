## 1. 系统概述

视图系统采用**统一视图引擎**架构，所有视图（看板、列表、级联、时间线、时间视图、路线图）共享统一的配置和渲染机制。

### 1.1 核心设计理念

- **统一配置**：通过 YAML 配置 `pm-view` 代码块定义视图
- **统一组件**：所有视图使用 `EntityCard` 组件显示实体
- **统一筛选**：多条件筛选在单个横向工具栏中
- **行内编辑**：列表视图支持单元格直接编辑
- **智能联动**：筛选条件级联更新
- **配置持久化**：代码块配置自动保存到文件

## 2. 配置系统

### 2.1 配置格式 (YAML)

```yaml
# 基本配置
mode: kanban              # 视图模式: kanban/list/cascade/timeline/timeview
entityType: feature       # 实体类型: version/project/feature

# 标题
title: 我的视图

# 实体筛选
version: ver_xxx          # 版本ID
project: proj_xxx         # 项目ID

# 高级筛选
filters:
  - operator: and
    conditions:
      - field: status
        operator: equals
        value: in-progress

# 卡片字段配置（控制 EntityCard 显示）
cardFields:
  required:               # 始终显示的字段
    - name
    - priority
  optional:               # 用户可选择的字段
    - status
    - owner
    - progress
    - tags
    - description
    - actions

# 列表列配置（仅 list 模式有效）
listColumns:
  - name
  - status
  - priority
  - owner
  - dueDate
  - progress

# 分组（看板/级联/路线图用）
groupBy: status           # status/priority/version/project/dueDate/trPhase

# 排序
sortBy: dueDate           # name/dueDate/priority/progress/created
sortOrder: desc           # asc/desc

# 限制
limit: 20

# 时间线方向
direction: horizontal     # horizontal/vertical/fishbone

# 级联视图选项
expanded: true
maxProjects: 5
maxFeaturesPerProject: 3
```

## 3. 视图渲染器

### 3.1 基类设计 (BaseRenderer)

```typescript
abstract class BaseRenderer {
  protected app: App;
  protected cache: EntityCache;
  protected config: ViewConfig;
  protected container: HTMLElement;
  
  abstract render(container: HTMLElement, entities: Entity[]): Promise<void>;
  abstract refresh(): void;
  
  // 公共方法
  protected getFilteredEntities(): Entity[];
  protected createEmptyState(message: string): HTMLElement;
  protected onEntityChange(entity: Entity): void;
  protected createToolbar(): HTMLElement;
  protected createFilterBar(): FilterBar;
}
```

### 3.2 看板视图 (KanbanRenderer)

**设计特点：**
- 按 `status` 或 `priority` 分组列
- 卡片可拖拽排序
- 支持新建列
- 卡片使用统一 `EntityCard` 组件

## 6. 交互规范

### 6.1 拖拽行为

| 视图 | 拖拽源 | 放置目标 | 行为 |
|------|--------|----------|------|
| 看板 | 卡片 | 列 | 更改状态/分组 |
| 看板 | 卡片 | 同一列 | 重新排序 |
| 列表 | 行 | 行 | 重新排序 |

### 6.2 行内编辑

| 单元格 | 触发 | 输入方式 | 保存 |
|--------|------|----------|------|
| 文本 | 单击 | 文本输入框 | 失焦/Enter |
| 下拉 | 单击 | 下拉选择 | 选择即保存 |
| 日期 | 单击 | 日期选择器 | 选择即保存 |
| 进度 | 单击 | 滑块 | 拖动结束保存 |

### 6.3 视图切换

```
用户点击视图切换按钮
    ↓
ViewEngine.switchMode(newMode)
    ↓
保存新配置到代码块 (saveViewConfig)
    ↓
重新创建 Renderer (createRenderer)
    ↓
调用新 Renderer.render()
    ↓
视图刷新
```

## 8. 数据流

```
1. 用户打开包含 pm-view 代码块的笔记
              ↓
2. Obsidian 触发代码块处理器
              ↓
3. ViewEngine.render() 解析 YAML 配置
              ↓
4. 创建工具栏 + 筛选栏
              ↓
5. 调用对应 Renderer.render()
              ↓
6. Renderer 从 EntityCache 获取数据
              ↓
7. 渲染 EntityCard 组件
              ↓
8. 用户交互（筛选/编辑/拖拽/切换视图）
              ↓
9. 更新 EntityCache → 刷新视图
```
