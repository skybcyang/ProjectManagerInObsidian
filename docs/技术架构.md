### 2.2 三层存储架构

```
┌─────────────────────────────────────────────────────────────┐
│ Layer 1: 内存缓存 (EntityCache)                              │
│ - Map<string, Version> versionCache                         │
│ - Map<string, Project> projectCache                         │
│ - Map<string, Feature> featureCache                         │
│ - 文件监听自动更新 (create/modify/delete/rename)            │
└─────────────────────────────────────────────────────────────┘
                              ↕
┌─────────────────────────────────────────────────────────────┐
│ Layer 2: Obsidian 元数据缓存 (metadataCache)                 │
│ - 自动解析 frontmatter                                      │
│ - 监听文件变更事件                                          │
└─────────────────────────────────────────────────────────────┘
                              ↕
┌─────────────────────────────────────────────────────────────┐
│ Layer 3: 文件系统 (Vault)                                    │
│ ProjectManager/                                             │
│ ├── 总览.md                                                 │
│ ├── Versions/                                               │
│ │   └── {版本名}.md                                         │
│ ├── Projects/                                               │
│ │   └── {项目名}.md                                         │
│ └── Features/                                               │
│     └── {特性名}.md                                         │
└─────────────────────────────────────────────────────────────┘
```

## 3. 核心机制

### 3.1 文件命名规则

| 实体 | 文件名格式 | 示例 |
|------|-----------|------|
| 版本 | `{版本名}.md` | `V1.0 Initial Release.md` |
| 项目 | `{项目名}.md` | `用户系统.md` |
| 特性 | `{特性名}.md` | `登录功能.md` |

> **注意**: v0.6.0 起不再在文件名中包含层级关系，改为通过 frontmatter 中的 versionId/projectId 关联

### 3.2 缓存同步机制

```
用户删除文件夹
    ↓
Obsidian 触发 'delete' 事件
    ↓
EntityCache.handleFileDelete(file)
    ↓
通过文件名匹配查找缓存项
    ↓
从对应 Map 中 delete(id)
    ↓
缓存与文件系统保持一致
```

### 3.3 视图模式切换

```
用户点击视图切换按钮
    ↓
ViewEngine.switchMode(newMode)
    ↓
保存新配置到代码块
    ↓
重新创建 Renderer
    ↓
调用新 Renderer.render()
    ↓
视图刷新
```

## 4. 视图系统

### 4.1 支持的视图模式 (v0.7.1)

| 视图 | 模式值 | 渲染器 | 主要用途 |
|------|--------|--------|----------|
| 看板视图 | `kanban` | KanbanRenderer | 类 Trello 拖拽看板 |
| 列表视图 | `list` | ListRenderer | 表格形式，支持行内编辑 |
| 网格视图 | `grid` | GridRenderer | 卡片网格布局 |
| 级联视图 | `cascade` | CascadeRenderer | 版本→项目→特性层级 |
| 时间线视图 | `timeline` | TimelineRenderer | 水平/垂直时间轴 |
| 时间视图 | `timeview` | TimeViewRenderer | 时间维度展示 |
| 燃尽图 | `burndown` | BurndownRenderer | 进度趋势分析 |
| 工作量统计 | `workload` | WorkloadRenderer | 工作量分布统计 |

### 4.2 统一卡片组件 (EntityCard)

**可配置字段：**
- `showPriority`: 优先级标记条
- `showStatus`: 状态徽章
- `showOwner`: 负责人
- `showDueDate`: 截止日期
- `showProgress`: 进度条
- `showTags`: 标签
- `smallTitle`: 小标题模式

### 4.3 列表视图列配置

```yaml
mode: list
entityType: feature
listColumns:
  - name
  - status
  - priority
  - owner
  - startDate
  - endDate
  - progress
```

## 6. 性能优化

| 场景 | 策略 |
|------|------|
| 大量文件加载 | 内存缓存 + 懒加载 |
| 频繁文件变更 | Obsidian 事件监听，增量更新 |
| 关系查询 | 通过 ID 弱引用，实时查找 |
| 视图渲染 | 原生 DOM，无框架开销 |
| 筛选过滤 | 内存中过滤，不重复读取文件 |

## 7. 扩展指南

### 7.1 添加新视图模式

1. 在 `view-engine/renderers/` 创建新渲染器类
2. 继承 `BaseRenderer`
3. 实现 `render(container: HTMLElement)` 方法
4. 在 `ViewEngine.createRenderer()` 中注册新视图
5. 更新 `ViewMode` 类型定义

### 7.2 自定义模板

1. 在设置面板中启用自定义模板
2. 编辑模板文件
3. 使用模板变量：`{{name}}`, `{{status}}`, `{{#if}}...{{/if}}`
4. 支持嵌套属性：`{{project.name}}`

### 7.3 使用配置验证

```typescript
import { ConfigValidator } from './utils';

const validation = ConfigValidator.validate(parsedConfig);
if (!validation.valid) {
  validation.errors.forEach(err => console.warn(err));
}
```

### 7.4 错误处理

```typescript
import { ErrorHandler } from './utils';

try {
  await operation();
  ErrorHandler.handleSuccess('操作成功');
} catch (error) {
  ErrorHandler.handle(error, '上下文信息', { category: 'user' });
}
```
