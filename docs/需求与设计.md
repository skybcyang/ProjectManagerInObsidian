# 需求与设计

> **项目目标**: 在 Obsidian 中实现一套完整的项目管理系统，支持版本、项目、特性三层结构化管理。
> 
> **当前版本**: v0.8.1

---

## 1. 核心需求

### 1.1 三层数据管理

| 层级 | 存储位置 | 核心字段 | 说明 |
|------|---------|---------|------|
| **版本** | `Versions/*.md` | id, name, status, startDate, endDate, owner, tags | 产品版本迭代 |
| **项目** | `Projects/*.md` | id, name, status, priority, versionId, owner, tags | 必须关联版本 |
| **特性** | `Features/*.md` | id, name, status, priority, versionId, projectId, startDate, endDate, progress, owner, tags | 必须关联项目 |

**数据存储原则**:
- 元数据放在 frontmatter 中
- 详细描述、进度反馈写入正文
- 使用 `[[WikiLink]]` 建立关联

### 1.2 视图与交互

| 功能 | 实现方式 | 状态 |
|------|---------|------|
| 统一视图 | `pm-view` 代码块，支持 3 种模式 | ✅ v0.8.1 |
| 看板视图 | `mode: kanban` 按状态分栏 | ✅ |
| 级联视图 | `mode: cascade` 版本→项目→特性，含进展/风险详情 | ✅ |
| 时间视图 | `mode: timeview` 甘特图，支持按负责人/项目分组 | ✅ v0.8.0 |
| 面包屑导航 | 层级路径，支持点击穿透 | ✅ |
| ICS 导出 | 导出特性截止日期到日历 | ✅ |
| 自定义模板 | 总览/版本/项目/特性页面模板 | ✅ v0.5.0 |

## 2. 数据模型

### 2.1 版本状态

| 状态 | 说明 |
|------|------|
| `planning` | 规划中 |
| `in-progress` | 进行中 |
| `completed` | 已完成 |
| `archived` | 已归档 |

### 2.2 项目/特性状态

| 状态 | 说明 |
|------|------|
| `backlog` | 待规划 |
| `todo` | 待办 |
| `in-progress` | 进行中 |
| `testing` | 测试中 |
| `completed` | 已完成 |
| `archived` | 已归档 |

### 2.3 优先级

| 优先级 | 说明 | 颜色 |
|--------|------|------|
| `critical` | 紧急 | 🔴 #ef4444 |
| `high` | 高 | 🟠 #f59e0b |
| `medium` | 中 | 🔵 #3b82f6 |
| `low` | 低 | 🟢 #22c55e |

### 2.4 分组方式

支持按以下字段分组：
- `status` - 状态
- `priority` - 优先级
- `version` - 版本
- `project` - 项目
- `startDate` - 开始日期
- `endDate` - 结束日期

## 3. 视图代码块配置

### 3.1 完整配置示例

```yaml
mode: kanban              # 必需: kanban/cascade/timeview
entityType: feature       # 可选: version/project/feature
title: 我的视图            # 可选: 自定义标题

# 实体筛选
version: ver-001          # 版本ID筛选
project: proj-001         # 项目ID筛选

# 或高级筛选
filters:
  - operator: and
    conditions:
      - field: status
        operator: equals
        value: in-progress
      - field: priority
        operator: in
        value: [high, critical]

# 分组
groupBy: status           # status/priority/version/project/startDate/endDate

# 排序
sortBy: endDate           # name/startDate/endDate/priority/progress/created
sortOrder: desc           # asc/desc

# 限制
limit: 20

# 卡片字段配置
cardFields:
  required: [name, priority]
  optional: [status, owner, startDate, endDate, estimatedDays, actualDays, progress, tags]

# 级联视图选项
expanded: true
maxProjects: 5
maxFeaturesPerProject: 3

# 时间线方向
direction: horizontal     # horizontal/vertical/fishbone
```
