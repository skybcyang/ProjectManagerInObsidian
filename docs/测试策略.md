# 测试

## 测试策略

| 层级 | 工具 | 覆盖范围 | 目标覆盖率 |
|------|------|---------|-----------|
| 单元测试 | Jest | 工具函数、服务方法 | 80% |
| 集成测试 | Jest | 服务间协作 | 60% |
| E2E 测试 | 手动 | 完整用户流程 | 核心流程 |

## 关键测试场景

### 数据验证
- [ ] 项目创建必填字段验证（id, name, status）
- [ ] 特性必须关联项目
- [ ] 项目必须关联版本

### 状态流转
- [ ] 正常状态流转
- [ ] 已完成返回其他状态需确认

### 文件操作
- [ ] 文件创建成功
- [ ] 文件更新成功
- [ ] 文件删除不级联，关联文件优雅降级

### 视图渲染
- [ ] `pm-view` 代码块渲染正常
- [ ] 看板视图按状态分栏
- [ ] 级联视图展示层级结构

## 属性面板测试要点

### 基础行为
- 面板唯一性：确保页面上只存在一个属性面板
- 外部点击关闭：点击页面其他区域应关闭面板
- 内容完整性：所有配置的控件正确显示

### 实体类型选择器
- 选项包含：特性、项目、版本
- 切换后视图刷新，代码块同步更新

### 视图模式特定控件
- **list 模式**: 显示"显示列"区域
- **kanban/grid 模式**: 显示"卡片显示字段"区域
- **kanban/cascade 模式**: 显示"分组方式"选择器
- **grid 模式**: 显示"列数"选择器

### 边界情况
- 无 sourcePath 时的处理
- 并发修改冲突处理
- 快速连续修改多个属性的稳定性

## 运行测试

```bash
npm test           # 运行所有测试
npm run test:unit  # 运行单元测试
npm run test:coverage  # 运行测试并生成覆盖率报告
```
