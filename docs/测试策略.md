- 面板唯一性：确保页面上只存在一个属性面板

## Storybook 组件测试

### 启动 Storybook

```bash
npm run storybook    # 启动开发服务器 http://localhost:6006
npm run build-storybook  # 构建静态版本
```

### 已覆盖组件

| 分类 | 组件 |
|------|------|
| **Components** | KanbanCard, KanbanColumn, EntityCard, StatusBadge, StatusPicker, ProgressPicker, DropdownMenu, FilterBar |
| **Views** | KanbanView, ListView, GridView, CascadeView, TimelineView, TimeView, BurndownView, WorkloadView |
| **Full** | FullKanbanBoard |

### Storybook 用途

1. **可视化测试** - 独立展示各个 UI 组件，确保样式正确
2. **组件文档** - 查看组件的各种状态和变体
3. **视觉回归测试** - 与 Chromatic 集成，自动检测 UI 变化
4. **开发调试** - 快速迭代和调试组件样式

### 添加新 Story

在 `src/stories/` 目录创建新的 `.stories.ts` 文件：

```typescript
import type { Meta, StoryObj } from '@storybook/html';

const meta: Meta = {
  title: 'Components/YourComponent',
  render: () => {
    const element = document.createElement('div');
    // 创建你的组件
    return element;
  },
};

export default meta;
```

## 运行测试

```bash
npm test           # 运行所有测试

npm run storybook  # 启动 Storybook
```
